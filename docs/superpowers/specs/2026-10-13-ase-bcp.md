# ASE character BCP

The third local tool connects to Sybase ASE and browses databases, owners, tables,
views and procedures. Tables support character BCP IN and OUT; views support OUT;
procedures are browse-only. IN appends to existing data. Native Windows file
dialogs select existing input files and output destinations, without uploads.

The distribution remains one Windows 10/11 x64 `nice-tools.exe`. It embeds a
pinned FreeTDS Sybase DB-Library, GNU libiconv, OpenSSL and their notices. ctypes
uses the DB-Library bulk API with TDS 5.0 in isolated subprocesses of the same EXE.
Source development can run without the DLL and reports that capability clearly.
User PCs do not need SAP clients, Python, Java or Internet access.

Character files support UTF-8, CP949 and EUC-KR, escaped field/row terminators,
batch size and optional preservation of identity values. IN includes all columns
in catalog order. Empty fields mean NULL; the BCP single-NUL marker means empty
text. This is a BCP character format, with no CSV quoting. Preflight streams the
whole file, validates encodings, field counts, lengths and numeric ranges, and
shows at most 20 rows. There is no fixed file byte limit. Unsupported binary and
generated data types are rejected for IN rather than guessed.

Passwords stay in process memory and worker stdin, never arguments, persistent
settings, logs or browser storage. Local JSON APIs require a custom header and
validate loopback Host/Origin. Sessions, file selections and single-use reviews
are random tokens. A transfer rechecks object identity, schema and file state.
OUT writes a sibling temporary file and replaces the destination after success;
failure/cancellation preserves the prior destination. IN batches may already be
committed when a transfer fails or is cancelled, and retry may duplicate rows.

Verification must cover source validation, HTTP boundary, subprocess lifecycle,
browser behavior and the actual one-file Windows EXE, including native DLL
loading and connection refusal. These checks do not establish successful ASE
round trips: a live ASE server is not available in this development environment.
